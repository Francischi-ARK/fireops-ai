# FireOps AI 92 秒旁白

00:00–00:05　这不是又一块消防大屏。FireOps 把报警帧变成责任闭环。

00:05–00:11　流程从 Modbus 火警帧开始，CRC、控制器、回路和点位都可核验。

00:11–00:18　值班员先看到设备信号；只有人工确认，系统才建立真实处置事件。

00:18–00:25　派发仍是人工决定。事件编号、证据和责任班组从这里开始绑定。

00:25–00:32　班组依次签收、出动、到场，每个按钮只解锁下一合法状态。

00:32–00:38　现场首报回到值班台，形成同一 event id 下的完整时间线。

00:38–00:45　AI 不直接操作设备。它拆解任务、查手册、补齐上下文，并把证据编号和工具轨迹同时交付。

00:45–00:52　主机故障不会挤进火警链。Agent 先检索点位、维保和手册，只生成维修草稿。

00:52–00:59　工单必须经过批准、开工和完成，不能跳步关闭，所有动作都有岗位和时间戳。

00:59–01:06　巡查图片和口述只生成隐患草稿，巡查员再选择网格责任人。

01:06–01:13　责任人开始整改、提交完成证据；工单 done 仍不等于隐患关闭。

01:13–01:20　巡查员复查通过后，finding 才变为 closed，证据链在这里收口。

01:20–01:25　企业档案汇总事件、工单、隐患和证据，并把人带回对应岗位流程。

01:25–01:29　证据不足时，AI 会列出缺项并拒绝建单。

01:29–01:32　让 AI 进入现场，但不越过现场的人。
