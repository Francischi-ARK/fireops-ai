# FireOps AI 参赛 Demo 设计

成片为 1920×1080、92 秒、30fps。画面以 FireOps 深色工业控制台为主，消防红表示风险与人工确认，证据橙表示处理中间态，闭环绿表示可验证完成。产品页面保持原貌，只增加局部描边、底部字幕和轻微推近，不使用无关特效。

旁白采用普通话女声 Tingting，语速克制、偏纪录片口吻，参考漫游类产品视频的平静讲述方式。全片不配商业音乐，让设备信号、岗位交接和安全边界成为注意力中心。

叙事顺序固定为：工业事件源 → 人工核实 → 跨岗处置 → AI 证据层 → 故障维保 → 巡查整改与复查 → 企业档案 → 安全拒答 → 最终边界。字幕、截图、点击和旁白共用 `timeline.json`。
