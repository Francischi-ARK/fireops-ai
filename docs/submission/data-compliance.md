# 数据来源与合规说明

> 对应赛事手册 6.2 / 9.1–9.4 要求，初赛随 PPT 简述、复赛单独成文。

## 1. 数据类型与来源

| 数据 | 来源 | 授权状态 |
| --- | --- | --- |
| 企业、设备信号、维保、隐患、站点数据 | 全部为本项目编写的合成数据（`demo-data/*.csv`、后端种子数据、`demo-data/copilot_scenarios.json`） | 自制，无第三方权利 |
| 证据图片（控制室记录、灭火器遮挡、疏散指示、平面图） | 为本项目生成的合成示意图（`assets/`） | 自制，无第三方权利 |
| 规范名称（GB 16281—2024 等） | 公开标准文献，仅在文档中引用名称与适用范围 | 公开信息引用 |

不包含个人信息、真实企业数据、真实警情数据、商业秘密或任何未经授权的数据。

## 2. 模拟逻辑与适用边界

- 合成数据用于验证产品流程：设备信号 → 人工核实 → 警情 → 调派 → 站端响应，以及风险规则评分；
- 五家虚拟企业的相对风险顺序、信号与维保时间关系均为人工设定，用于演示特定规则分支；
- 合成数据不代表任何真实辖区、企业或救援站的风险水平，不能据此推断真实世界结论；
- 所有演示页面、接口返回和运行记录均带 `is_simulation: true` 与 `external_system: "none"` 标记。

## 3. 隐私与脱敏

- 不采集、不存储任何个人数据；演示角色（值班员、指挥员）均为虚构岗位名称；
- 无需脱敏：输入数据本身即为虚构。

## 4. 模型使用披露

- Live 模式默认调用 ModelScope（魔搭）免费推理 API 的 Qwen 系列模型，仅传入合成文本与合成图片说明，不涉及真实数据；
- 商业 API 调用环节：仅 Agent 规划（意图理解、信息抽取、追问、摘要、工具选择）；费用假设：免费额度内；潜在锁定风险：低——接口为 OpenAI 兼容协议，替换服务只需修改 `COPILOT_MODEL_BASE_URL` / `COPILOT_MODEL_API_KEY` / `COPILOT_MODEL_NAME` 三个环境变量；
- 模型不可用时系统自动回退到确定性模板，Scenario 模式完全不依赖外部模型。

## 5. 行业边界与风险提示

- 不连接真实 119、消防物联网、车辆定位或企业生产系统；
- 不自动确认警情、不自动调派、不自动提级、不控制任何真实设备；
- 设备火警信号不等于消防救援警情，必须经人工核实；
- AI 输出（风险分析、处置建议、简报草稿）仅作辅助参考，不替代消防救援机构、监督人员和现场指挥的最终判断；
- 对信息缺失、数据过期、模型幻觉风险，系统在界面上显式提示并支持安全拒答。

## 6. 知识产权

- 代码与文档为本团队原创；第三方依赖清单与许可证见 `backend/pyproject.toml`、前端 `assets/` 内库的原始许可；
- 计划以 Apache-2.0 或 MIT 发布最小可复用模板（复赛确定）。
