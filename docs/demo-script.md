# 三幕 Demo 脚本与证据清单

> 对应 dev-001 验收：90 秒讲述排练用脚本 + 初赛/复赛证据清单。
> 全程边界口径：合成数据、未连接 119、不控制真实设备、AI 不替代现场指挥。

## 90 秒视频脚本

### 第一幕：问题与入口（0–15 秒）

- 画面：总队监测中心，皓源新能源（虚拟）一条设备火警信号进入列表。
- 旁白：一起设备火警信号进来，信号、维保、图纸、预案分散在四个地方。过去靠人拼，现在交给 Copilot 先拼一遍。

### 第二幕：主线，场景 B 真实警情（15–55 秒）

- 15–25 秒：打开 Copilot，输入员工报警文本和厂房平面图。Agent 显示任务理解、缺失字段追问（失联人员最后出现位置），逐步调用 `get_signal_context`、`get_site_packet`、`recommend_station`。
- 25–40 秒：证据抽屉展开——危险源、入口、水源、平面图、站点状态逐条带来源；生成指挥台简报和调派草稿，明确标注“草稿，待确认”。
- 40–50 秒：指挥员点确认，调派写入时间线；切到救援站终端，签收、出动、到场、首报。
- 50–55 秒：同一事件编号下，企业端收到整改待办。三个角色，一条时间线。

### 第三幕：边界与可复现（55–90 秒）

- 55–70 秒：快切场景 A——探测器报警与当日上午维保测试时间相邻，Agent 发现冲突，只生成待核实草稿，不建警情；场景 C——启明电子数据断报、上报模糊，Agent 列出缺口、全部标注未知，不推荐调派。
- 70–85 秒：展示一次运行的完整轨迹：输入摘要、工具调用、证据引用、模型信息、人工动作，可回放复盘。
- 85–90 秒：收尾字幕——合成数据、未连接 119、不控制真实设备、AI 不替代现场指挥。Scenario 模式离线可复现，README 从零跑通。

## 现场答辩备用口径

- 模型只做非确定性工作：意图理解、信息抽取、追问、摘要、工具选择；风险评分、状态流转、权限、最终动作全是确定性代码。
- 模型不可用时自动回退确定性模板，Demo 不会死在评委面前。
- 越权工具调用由服务端 schema + 状态机 + 权限三层拦截，测试覆盖。

## 模型服务决策

- Live 模式默认走 ModelScope（魔搭）免费推理 API 的 Qwen 系列：赛道共创单位、零成本、国内直连，符合“商业 API 披露”要求。
- 通过环境变量配置 base_url / api_key / model，可换任何 OpenAI 兼容端点；披露材料写明替代方案与迁移成本（改三个环境变量）。
- 语音输入不作为亮点：Demo 用预录转写文本，界面保留“语音报障”入口和来源标记。
