# FireOps 90 秒 Demo 脚本（中枢三链）

> 面向 GOAI 无界应用 · AI+工业制造。全部为合成数据，不控制真实设备。

## 开场（0–10 秒）

- 画面：工作台首页
- 旁白：星澜新能源汽车工厂消防设备运维 Agent。火警主机 Modbus 事件、维保逾期、巡查隐患进同一个工单中枢。

## 主链：火警闭环（10–45 秒）

1. 打开 `#/monitoring`，选电池车间，点「模拟火警帧」
2. 自动跳转 `#/incidents`，同一条信号待核实 →「确认火警」→「派发工单」
3. 打开 `#/station`，微型消防站收件箱出现处置工单，点签收/出动

旁白：监测不是孤岛，注入即入核实队列；派发后班组统一收件箱可见。

## 辅链：故障诊断（45–65 秒）

1. 监测页点「模拟主机故障」→ 跳转维保组收件箱，已有维修草稿
2. 可选：点「用 Copilot 诊断」绑定中枢信号跑场景 C，确认派发后仍回班组终端

旁白：故障不进 119，进维修工单；Copilot 接中枢信号，不再旁路新建。

## 加分：巡查多模态 + 网格闭环（65–85 秒）

1. `#/inspections` →「新建巡查识别」→ 选照片 + 口述 → 识别 → 确认派发
2. 自动进入 `#/owner` 网格待办 → 开始整改 → 标记完成 → 回到巡查「复查通过并闭环」
3. （可选 5 秒）`#/copilot` 场景 E：气体灭火延时只出手册咨询，不派控制工单

## 收尾（85–90 秒）

- 安全边界字幕：不控制真实设备、不自动启动灭火、对外报警由人执行
- 可导出 Copilot 审计包复核证据链
